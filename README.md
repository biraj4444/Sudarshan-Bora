# Sudarshan Bora portfolio

Static site, no build step. Upload this folder to any static host (Cloudflare Pages, Netlify, GitHub Pages, Render static site).

Edit `assets/js/config.js` to change:
- email, phone, phoneRaw, location (anything left "" is hidden automatically)
- profileImage and thumbnail (project screenshot)

Pages: index.html, resume.html, projects.html, skills.html, contact.html.
Skill pictures are built-in vector icons, so nothing external can break.
The Resume page has a "Print or save as PDF" button.
